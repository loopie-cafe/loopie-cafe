# Loopie Cafe Website

A premium cinematic coffee shop website inspired by modern luxury coffee brands.

## Features
- Cinematic scroll-controlled coffee preparation animations.
- Interactive coffee roasting experience.
- Animated coffee temperature counter.
- Smooth transitions between coffee drinks.
- Premium product showcase.
- Interactive menu with categories and prices.
- Horizontal cafe photo gallery.
- Google Maps integration.
- WhatsApp contact integration.
- Responsive Arabic RTL design.
- Smooth scrolling and modern animations.

## Technologies
- HTML5
- CSS3
- JavaScript
- Canvas API
- Three.js
- Lenis Smooth Scroll

## Project Structure
- `index.html` - Main website.
- `data.js` - Cafe content and configuration.
- `scene3d.js` - 3D scenes and effects.
- `assets/` - Images, animations, and media files.

## Deployment
Hosted using GitHub Pages.
